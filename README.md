This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, create google cloud OAuth credentials in https://console.cloud.google.com and put the client ID and client secret in the .env.local file.

Next, run the development server:

```bash
npm run dev
```

Navigate to [http://localhost:3000](http://localhost:3000) in your browser to visit the website.
